This repository contains the code used to produce figures in paper "Uniaxial poroelastic tendon model with fibre recruitment reveals hysteresis"
Solver_scripts contains the numerical solver and additional scripts used to compute other variables needed for plotting
Simulations_and_plots contains scripts which run the numerical experiments described in the paper and produces the corresponding figures
slanCM is a package used for the colour schemes in the plots, downloaded here: https://uk.mathworks.com/matlabcentral/fileexchange/120088-200-colormap
